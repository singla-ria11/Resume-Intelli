# Resume-Intelli

**Resume-Intelli** is a full-stack AI-powered resume builder that helps users create professional resumes using customizable templates and AI-assisted content enhancement.

## 🚀 Live Demo

[Resume-Intelli](https://resumeintelli.netlify.app)

## 💻 Repositories

* **Frontend:** [Resume-Intelli Frontend](https://github.com/singla-ria11/Resume-Builder-Frontend)
* **Backend:** [Resume-Intelli Backend](https://github.com/singla-ria11/Resume-Builder-Backend)

## ✨ Features

* AI-powered resume content enhancement
* Customizable resume templates
* User authentication and protected routes
* Create, edit, and manage resumes
* Persistent resume data using MongoDB
* Responsive user interface
* State management using Redux
* Route-based navigation with React Router

## 🛠️ Tech Stack

### Frontend
* React
* Redux Toolkit
* React Router
* JavaScript
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### AI Integration

* OpenAI API

## 🏗️ Architecture

Resume-Intelli follows a separate frontend-backend architecture:

**React Frontend → Express/Node.js API → MongoDB**

The frontend communicates with the backend through REST APIs, while the backend handles authentication, resume data, and AI-powered content enhancement.

## 📂 Project Structure

The project is maintained in two separate repositories:

Resume-Intelli
├── Frontend
│   └── React + Redux + React Router
│
└── Backend
    └── Node.js + Express + MongoDB

## 📌 Purpose

This project was built to demonstrate practical full-stack development skills, including frontend development, state management, REST API integration, database management, authentication, and OpenAI API integration.
